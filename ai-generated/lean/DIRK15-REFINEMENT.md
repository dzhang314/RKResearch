# Unrestricted order-fifteen DIRK: native cubic and two-ended support

This cumulative source overlay is additive to published main `182d77cc`.
It retains the initial structural overlay byte for byte, and deliberately
does not update the project's default imports or its version pins. Use
`lake build RKCert.Dirk15SupportRefinement` on Lean/Mathlib v4.36.0.
No stage bound or existence claim is added. The unconditional Lean floor
at order fifteen remains 20; the established standalone mathematical
21-stage exclusion is not yet completely formalized.

## New verified original-array deductions

- `RKCert.Paired.order15_minimal_reverse_nonlocal` eliminates the
  actual *node-local reverse cubic* alternative from the C(2),
  rank-two M4 branch. The same weighted cut applies in non-C(2) through
  `order15_nonC2_reverse_nonlocal`, with no assumption of a zero first
  row. The paid original grade flags supply the full input to the
  generic weighted four-debut contradiction. Zero-base and repeated-clock
  physical rows remain in the chronology. The padded contraction has
  exact paid primitive and commutator corrections; it is not treated as
  an RK method.
- `order15_nonC2_reverse_orbit` identifies the genuine full marks
  through M7. `order15_nonC2_tau_clean_radau` then derives the fixed
  Radau port condition at an actual b-active, cubic-clean row. It does
  not classify the dirty/zero-weight rows and does not exclude non-C(2).
- `order15_minimal_true_ghost_sandwich` derives the true simultaneous
  physical kernel between F3 and F7 with no extra first-escape premise
  in that branch. `order15_nonC2_cubic_channels` also proves ordinary
  F3 zero on both reverse channels in the non-C(2) chart. The 3+2 proof
  recovers two different nonzero reverse pivots and uses exact
  characteristic-zero multiplicity algebra, not ordering the field.
- `order15_actual_signatures` derives pair injectivity and the
  two-per-clock cap from a genuine ordinary E7 head presentation and
  retained coordinates where the invariant core vanishes. It does not
  provide those head hypotheses itself. The distinctness argument uses
  actual one-clock signed relations, not distinct abscissae.
- `order15_forward_quartic_cut`, `order15_reverse_quartic_cut`, and
  `two_ended_gram_of_mixed` derive exact primitive and two-ended Gram
  *vanishing* from the documented true geometric/mixed-trace inputs.
  The first forward coordinate is chosen without filtering output weights.
  The reverse proof uses only the pivot's proved nonzero weight.
- `order15_ordinary_core_rank` proves the maximal core lies in F6
  and has dimension at most 3+e for the f6=5+e, f7=6+e charts. Equality
  leaves an actual invariant hyperplane in F5 with both succeeding
  gains unit; this file does not exclude that case.

## New arithmetic transfer interfaces, not numerical certificates

- `RKCert.FixedPolynomial.exists_specialization`: specialization of
  polynomial equations in *scaled integral roots* to a residue-field
  extension of one prime field, using native Mathlib integral closure
  and lying over. The whole characteristic-zero field is never reduced.
- `no_common_eval_of_good_prime`, `parameterNorm_degree_le`, and
  `parameterNorm_zero_of_common_root`: fixed integer resultant transfer
  with exact degree preservation, an affine-pencil degree cap, and the
  resultant necessary condition at an actual root. A scan of parameter
  values in a prime field is not accepted as a characteristic-zero proof.
  Neither any Radau Gram table nor any free-pencil companion-compound
  norm has yet been imported as a checked nonvanishing certificate.

The shared weighted four-debut backend consists exactly of
`DirkWeightedFour{Interface,Heads,Cut,Complete}`. Its slim interface
does not import the even-order producer or grids. No baseline proof
file is replaced. This overlay is additional support, not a requested
publication or change to the strongest-bound table.
