# Reuse of Mathlib in the algebraic RK development

The audit is against Mathlib v4.36.0, commit
`fc4f59e577feb1a4956671bc04ac18aaaf8cd842`. We prefer a standard definition
or theorem when it replaces local code without restricting the coefficient
ring or the class of tableaux. There is no dependency on a separate RK or
ODE library.

| Area | Mathlib declarations | Decision |
| --- | --- | --- |
| Stage vectors and evaluations | `Matrix.mulVecLin`, `LinearMap.mulLeft`, `dotProductEquiv`, `Fintype.linearCombination` | Use as implementations of the existing small RK-facing interfaces. |
| Reverse pairing | `Matrix.mulVec_transpose`, `Matrix.dotProduct_mulVec` | Use directly for the reverse row identity. |
| Stage chronology | `Submodule.pi`, `LinearMap.injOn_iff_surjOn` | Use for support and the invariant subspace step. The proof that the physical triangular operator is injective on the specified support is still needed. |
| Ranks | `Subspace.finrank_add_finrank_dualAnnihilator_eq`, `Submodule.finrank_lt_finrank_of_lt`, `LinearMap.finrank_le_finrank_of_injective`, `Module.finrank_fin_fun` | Reuse the standard results. The subspaces generated by RK weights and the probes separating them are defined here. |
| Base change | `Ideal.exists_maximal`, `Ideal.Quotient.field`, `Ideal.Quotient.mk` | Use Mathlib's residue-field construction; prove only the RK-specific preservation conditions. |
| Finite rooted trees | `RootedTree`, `RootedTree.subtrees`, `RootedTree.subtrees_disjoint`, `BinaryTree` | Keep the finite recursive RK type. Mathlib's general type need not have finitely many vertices, and its finite binary type is not an arbitrary-branching tree API. The general subtree lemmas are useful candidates for a future finite-tree bridge. |
| Polynomial certificates | `Polynomial.resultant`, `Polynomial.isUnit_resultant_iff_isCoprime`, `Polynomial.shiftedLegendre`, `EuclideanDomain.gcd_eq_gcd_ab` | Use these APIs where the proof calls for them. The certificate code verifies chosen identities; it does not implement a resultant or GCD algorithm. |
| Cauchy and weighted moments | `Fintype.linearCombination`, ordinary finite-dimensional linear algebra and polynomial APIs | Keep one shared proof of the Cauchy kernel lemma. We did not find a direct replacement with the characteristic and degree hypotheses this development needs. |
