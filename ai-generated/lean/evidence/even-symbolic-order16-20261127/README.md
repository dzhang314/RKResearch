# Exact rational order 16 in 49 strict SDIRK stages

`RKResearch.Certified.EvenTerminal16.witness` proves ordinary order 16,
failure at the next order, and a lower triangular stage matrix with
common nonzero diagonal 1/4. The proof uses the analogue of the
[order-14 symbolic tail](../even-symbolic-order14-20261127/README.md)
and removes 7 actual copied whole strict rows. The 41-stage
preparation is itself proved to have order 14, and the typed audit
also checks 7 actual locally exact head rows, 4 of them
with one additional grade. The quadratic Gram evaluation is not
used at this order in the Lean proof.

## Replay

Use the [previous replay](../even-symbolic-order14-20261127/README.md)
first, retaining its temporary directory as `work`. From the repository
root, the old modules are already available and only four compilations
are required:

```sh
repo="$PWD"
res="$repo/ai-generated/research/even-terminal-head-sharing"
ev="$repo/ai-generated/lean/evidence/even-symbolic-order16-20261127"
cp "$ev"/*.lean "$work/"
(cd "$work" && sha256sum -c "$ev/sources.sha256")
cd ai-generated/lean
lake env bash -c '
  export LEAN_PATH="$1:$LEAN_PATH"
  cd "$1"
  for mod in EvenPrep14Data ProofEvenPrep14 Even16Data ProofEven16; do
    lean -j1 -o "$mod.olean" "$mod.lean" || exit
  done
  lean -j1 Audit16.lean
' _ "$work"
```

Both matrices can be regenerated entry by entry and the two symbolic
proof files regenerated byte for byte:

```sh
python3 "$res/build_terminal_family.py" "$res/tableau-10.json" --out "$work/data" --through 16
(cd "$work/data" && sha256sum -c "$ev/fixtures.sha256")
python3 "$res/higher_prep_receipts.py" 14 "$work/data" "$work"
python3 "$res/make_even_prep.py" 14 "$work" "$work"
python3 "$res/terminal_receipts.py" 16 "$work/data" "$work"
python3 "$res/make_even_terminal.py" 16 "$work" "$work"
(cd "$work" && sha256sum -c "$ev/sources.sha256")
```

Lean 4.36.0 with matching Mathlib compiled the proof and its typed
import, with only `propext`, `Classical.choice`, and `Quot.sound`.
