# Clock-local annihilators

This generic Lean result constructs the greatest clock-invariant
subspace contained in a given subspace. It proves the equality
criterion and shows that the clock-local part of an annihilator is
unchanged on adjoining all diagonal clock multiples to the space
being annihilated.

The body was checked with Lean 4.36.0 and Mathlib
fc4f59e577feb1a4956671bc04ac18aaaf8cd842 against 14 previously
measured project dependencies. The separate typed audit checked four
examples and three named stock axiom reports. This result does not
assume any order or imply a new stage bound by itself.
