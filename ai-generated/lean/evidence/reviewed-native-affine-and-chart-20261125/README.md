# Affine prefix order and two exact scalar interfaces

A normalized linear combination of original rows at one nonzero
clock earns `HasOrder q` on the unchanged original prefix before
its last possible receiver, after rescaling the matrix and the
combined receiver weights by the reciprocal clock. The generic
theorem assumes that the combination annihilates the q-th defect
space. At a paid minimal-rank grade at least three, the companion
criterion is exactly that it annihilates the quadratic defect and
its matrix advance. In particular no single clean row is required.

For explicit order 17, the native ordered primitive theorem
discharges the quartic hypothesis of the earlier conditional
27-stage floor. The Radau and origin mesh hypotheses remain explicit.
This module does not import the archived replay cone.

For the fixed SDIRK construction, the chart adapter derives the
actual short and top word payments from the supplied exact chart
laws. Three scalar cells are paid by the allowed taps; the fourth
is equivalent to the scalar calibration under the specified
nonzero guards. The theorem is conditional; there is no checked
root, instantiated chart, or eleven-stage tableau in this batch.

Four modules compiled and were individually kernel-replayed on
Lean 4.36.0 and pinned Mathlib. The named audit checks found only
standard axioms.
