# Native paid-window geometry for 24-stage ERK of order 16

The certificates use the reviewed order conditions, `HasOrder 16 A b`, on the original 24 stages of an explicit method. The two conclusions have different hypotheses.

* If the seventh defect space has dimension eight, `width24_strong_actual_ports_and_origin` constructs the three contrast rows and proves that their first row is physical row zero. It supplies the forward and reverse polynomial moments without taking the contrast mask as an extra assumption.
* If the seventh defect space has dimension seven, `width24_ordinary_weak_head` supplies a nonzero rank-two weak head. With at least five contrast clock values, the separate census theorem supplies both interior ports. This result does not exclude that branch.

Both arguments use the same checked lemma for two successive clock multiplications paid in the same defect space: the multiplication lowers the degree of the fitted reverse polynomial. The two arguments also use the same physical seed-census lemma.

The [strong-three scalar exclusion](../../../lower-bounds/conditional/erk_order16_strong_three_sign_windows_20261124.md) is proved separately in mathematical prose. It is not part of this Lean certificate, and the packet makes no new unconditional stage-count claim.

`rebuild-order.txt` lists source and audit files in dependency order. `result.json` records the Lean and Mathlib pins, all 35 individual kernel replays, and the six source audits. Existing imports are supplied by the reviewed repository at the pins shown there.
