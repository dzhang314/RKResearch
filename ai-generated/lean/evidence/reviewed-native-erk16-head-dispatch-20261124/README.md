# Native width-24 dispatch and weak-five moments

For an explicit 24-stage tableau over an ordered field satisfying
the reviewed predicate `HasOrder 16 A b`, the seventh defect space
has dimension seven or eight, and the first reverse seed vanishes.
The dispatcher returns the corresponding actual physical data. In the
dimension-seven case it also identifies whether the contrast has four
or five supported clocks. The dimension-eight case is excluded by the
separate checked rank-eight endpoint.

The weak-five adapter derives all six local moments and the global
polynomial tests through degree five from the `HasOrder` tableau
and its actual five-clock mask. Multiplication by X removes the origin
from the grouped law; the true four-clock nodal hull then pays all
the listed global tests, including the constant test. The fixed-sign
factor budget and the grouped-moment wrapper are independent of the
tableau.

Neither weak scalar exclusion is asserted. The modules compiled and
were individually kernel-replayed on pinned Lean 4.36.0 and Mathlib.
The typed endpoint audits found only standard axioms.
