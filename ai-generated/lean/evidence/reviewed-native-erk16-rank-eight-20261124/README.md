# Order 16: exclude rank eight and split the rank-seven case

Over any ordered field, a strictly lower triangular 24-stage tableau
satisfying the reviewed order conditions `HasOrder 16 A b` cannot have
a seventh defect space of dimension eight. The endpoint theorem has no
premise on the first reverse seed: the native tableau adapter obtains
the necessary zero seed from the order conditions.

The decreasing pivot order uses two signed moment comparisons and a
strict sign change at a simple root. The proof bounds polynomial
increments over the ordered field by a finite sum of absolute
coefficients. It needs neither real-root existence nor topology imports.
Together with the checked increasing pivot order it excludes both orders
of the distinct pivots.

For seventh defect rank seven, a separate native theorem constructs
the ordinary weak head and proves its actual contrast has either four
or five supported clocks. Its reusable lower-count lemma uses only
characteristic-zero paid moments. Neither weak scalar exclusion,
nor the 25-stage lower bound without rank hypotheses, is asserted here.

The six modules were compiled and individually kernel-replayed using
Lean 4.36.0 and the pinned Mathlib. The three audits found only standard
axioms for the named declarations in the evidence record.
