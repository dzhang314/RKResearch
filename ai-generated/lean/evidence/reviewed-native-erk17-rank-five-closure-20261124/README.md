# Order 17: exclusion of the tiny rank-five branch

A four-clock feed is enumerated by the first original row on each
clock. If the clock support includes zero, the three remaining
clocks give the opposed 3+2+1 scalar moments with weights X and 1.
If zero is absent, the origin row forces the polynomial to vanish at zero, and the
forward 4+3 tests apply after factoring X.

The final tableau theorem uses the reviewed `HasOrder 17 A b`.
It excludes the rank-five branch of a strict 26-stage tableau with
nonzero first reverse seed and the indicated tiny local frame.
It does not exclude the rank-four branch or assert the unconditional
native order-17 bound.

Three modules compiled and were individually kernel-replayed on Lean
4.36.0 with pinned Mathlib. The audit's named declarations reported
only standard axioms.
