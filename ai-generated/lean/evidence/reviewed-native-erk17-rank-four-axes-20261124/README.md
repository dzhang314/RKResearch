# Order 17: actual rank-four axes and orbit

The rank-four theorem uses the reviewed `HasOrder 17 A b` for
a strict width-26 tableau with a nonzero first reverse seed and an
actual tiny local frame. It proves that r=2, that the hidden kernel
is contained in the fifth forward defect space, and that the sixth
forward defect space has rank seven. The paid axes and orbit give
the corresponding off-axis contrast exclusion and at least eight
ordinary supported reverse clocks for the head seed. No refined
joint-label count or unconditional native stage bound is claimed.

A separate order-eight module applies the generic single-defect
sufficiency theorem when the short words and actual top
factorization have been proved. The four top pairings form a 2 by 2
matrix. If the supplied taps cancel three entries, the remaining
condition is one exact scalar calibration. The converse requires an
exact probe identity. This module does not verify a donor tableau or
claim a new SDIRK construction.

Eight modules compiled and were individually kernel-replayed on Lean
4.36.0 with pinned Mathlib. The audits found only standard axioms.
