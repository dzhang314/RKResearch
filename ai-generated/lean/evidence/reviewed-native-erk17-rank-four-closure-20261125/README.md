# Order 17: exclusion of the tiny rank-four branch

For a strict width-26 tableau satisfying the reviewed `HasOrder 17 A b`,
the tiny local frame with nonzero first reverse seed cannot have a
four-dimensional hidden kernel. The refined count uses the actual
supported pairs of a clock and an axis value, not a count of physical
rows or of first clocks alone. The original width and the paid count
force all sixteen head labels and four contrast clocks to occur. The
resulting clean four-clock feed is excluded by the checked scalar
dispatcher. This closes the rank-four case; it is not the full native
stage bound from all possible first reverse seeds.

Two separate generic modules prove that at a paid minimum-rank grade
at least three, a row is clean exactly when its quadratic residual
and the actual matrix advance of that residual both vanish. No
grade-three base hypothesis is supplied. Two unequal live clocks
give the one-seed chain; a single live clock forces the independent
matrix advance. The typed client passes this criterion to the
existing endpoint theorem.

The explicit order-16 rank-three carrier theorem earns forward
payments from the original rows, without a clock-simplicity or
row-count premise. It excludes vanishing of the reflected
contrast polynomial at the original origin. It does not exclude all
weak-four or weak-five tableaux.

Thirteen modules compiled and were individually kernel-replayed on
Lean 4.36.0 and pinned Mathlib. The four audits found only standard
axioms.
