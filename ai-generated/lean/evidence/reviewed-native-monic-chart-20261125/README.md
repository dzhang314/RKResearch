# Monic projection and field specialization

A monic scalar projection of a polynomial-linear endomorphism gives a coefficient-linear left inverse by monic division in each coordinate. The inverse need not be polynomial-linear. Consequently the image is saturated with respect to regular coefficient scalars. For a monic chart quotient this lets one cancel such a scalar before evaluating the chart, without assuming its image under evaluation remains nonzero.

The independent common-diagonal result applies a supplied field stage floor to the original reviewed `HasOrder p A b` over a commutative ring. A nonunit diagonal is already handled by the explicit branch. For a unit diagonal it suffices to find a field image on which a chosen nonnilpotent scalar survives. The package does not certify any numerical exceptional characteristic set for the order-six chart.
