# Ordered scalar tools, affine donor counts, and an SDIRK contraction

The normalized affine receiver gives a lower bound on the number of
distinct effective nonzero clocks strictly before the receiver cut.
A clock is effective only if its actual aggregate signed weight is
nonzero. The count is the integer quotient q/2 and uses a shifted
Cauchy matrix over characteristic zero, with no sign assumptions.

The double-anchor quotient pays a second independent polynomial mean
and gives the monic normalization. The degree-eight Legendre comparison
uses the original ordered field and exact polynomial integration. It
excludes three distinct interior critical points with the stated common
quadratic factor, without requiring real closure, root splitting, or
a topology library. The physical weak-four tableau adapter is separate.

The diagonal-twin theorem and checked 12-to-11 typed use preserve
reviewed order and the strict SDIRK convention from the corrected-row
premises. The separate exact integer abscissa audit is not a proof
of donor existence or of those row premises.

axioms.
