# Rank of a restricted pairing and a three-row obstruction

The generic three-row result rules out three proportional reverse-residual rows in a strictly causal operator, provided at least two distinct clocks carry nonzero mass and the annihilating row is nonzero at any active clock of value zero. It does not assume the operator is itself a Runge–Kutta method. In the [ordinary order-13 clean-square argument](../../../research/erk13/ordinary-clean-square.md), one obtains such an operator by compressing original classes of indistinguishable stages; that mathematical argument is conditional on the stated head radius and defect-space rank.

The independent pairing result gives a rank loss of at most twice the codimension when both arguments of a finite-dimensional pairing are restricted to one subspace. It requires neither a symmetric form nor an ordered field.
