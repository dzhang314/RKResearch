# A characteristic-zero stage obstruction has only finitely many possible exceptional characteristics

**Status:** Written mathematical theorem and proof. This note does not supply a
new Lean certificate, an integer obstruction certificate, a list of exceptional
primes, or an all-characteristics 18-stage theorem.

## Statement

Fix an order p, a stage threshold L, and a class of Runge–Kutta tableaux
presented at each size s by polynomial equations with integer coefficients.
The standard strictly explicit class and the denominator-cleared rooted-tree
order convention meet this hypothesis. If no member of this class of order
at least p and size s<L exists over any characteristic-zero **field**, then
there is a positive integer N, depending only on the fixed class, p, and L,
with the following property:

> In any unital commutative ring R carrying such a forbidden-size tableau,
> N times 1_R is zero.

In particular, the lower bound s≥L holds over every positive-characteristic
field whose prime characteristic does not divide N. Over rings of positive
(possibly composite) characteristic m, a counterexample requires m to divide
N. Dividing N is a necessary, not a sufficient, condition for an exception.

## Proof

For each nonnegative s<L, start with an integer polynomial ring in the
allowed tableau entries and output weights. For the explicit class, take a
variable for each strict lower-triangular entry, set all other matrix entries
to zero, and take s weight variables. In this ring, every elementary stage
weight and output weight Φ(t) is an integer polynomial by induction on t.
Form the ideal generated by γ(t)Φ(t)−1 for each rooted tree of order at most p
and by all polynomial class constraints. Let U_s be the quotient ring. Its
universal tableau satisfies all these constraints; conversely every actual
candidate over a unital commutative ring R gives an evaluation homomorphism
U_s→R preserving 1.

We claim that a positive integer N_s vanishes in U_s. If not, localize at
the nonzero integers. This localization is not the zero ring: 1/1=0 there
would imply n·1=0 in U_s for some nonzero integer n. It is a nonzero
Q-algebra and has a maximal ideal. Its residue field is a characteristic-zero
field, because every nonzero rational maps to a unit and the field is
nonzero. The image of the universal tableau in this field contradicts the
assumed stage obstruction. This proves the claim. If the given obstruction
already covers all characteristic-zero *rings*, the localization and residue
field argument is unnecessary: a characteristic-zero U_s would itself
contradict the hypothesis. If U_s is the zero ring, take N_s=1.

Take N to be the product of the finitely many positive N_s (the empty
product is one). A forbidden-size tableau over R of size s gives U_s→R,
so N_s·1_R=0 and hence N·1_R=0. This proves all the assertions.

## Application and limits

Applying the verified characteristic-zero explicit order-12 bound with
L=18 gives the **existence** of such an N for order 12. It does not justify
reporting 18 as a uniform lower bound over all nonzero rings: the independent
verified arbitrary-ring order-12 bound remains 16. The argument does not
show which primes divide any witness N, nor whether any exceptional-size
tableau actually exists at a prime dividing it.

The presentation also permits a *unit* requirement on an element f:
introduce an auxiliary variable z and the equation fz−1=0. Requiring a
nonunit to be nonzero in a general ring, or requiring ordered-field
positivity, is not just this polynomial equation; no such broader transfer
is claimed. A list of actual exceptional primes would require additional
effective certificates or separate prime-by-prime results.
