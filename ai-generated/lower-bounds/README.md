# Lower bounds and proof fields

The table holds over the reals and, by real-closed-field transfer, over **any ordered field**. Finite classical order conditions and stage-pattern constraints are rational polynomial equalities and inequations. If an ordered field admitted a counterexample, so would its real closure, and hence so would the reals. This argument does not extend a lower bound to unordered fields.
