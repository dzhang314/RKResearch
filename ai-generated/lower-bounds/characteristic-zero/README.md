# Characteristic-zero lower bounds

These arguments need no ordering of the unknown coefficients. The strict SDIRK lower column is characteristic-zero throughout. For unrestricted DIRK, direct proofs match the current table at orders 12–16 and 18–20. For ERK, the order-12 floor is 18; independently audited floors at orders 16–20 are 24, 26, 27, 29, 30, which need not match the stronger real table.
