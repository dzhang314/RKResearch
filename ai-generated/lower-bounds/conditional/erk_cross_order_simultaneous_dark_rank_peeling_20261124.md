# Simultaneous causal row peeling at a lower order: actual stage-floor differences pay for lost marked rank

24 November 2026 UTC. General characteristic-zero statement for arbitrary real, complex or other field-valued strictly explicit ordinary Runge–Kutta data, including signed/zero weights, repeated or exterior knots. This is a physical, FULL NONLINEAR through-target-order deletion theorem, not a law asserting that a rank-deficient observation always means a dead individual stage. Ordinary coefficients of the input tableau need be exact only to the target order q used for the peel; the cross-order application uses a tableau originally exact to p≥q. The new aspect is the joint rank over all selected high-equal positions and its comparison with separately established minima at DIFFERENT orders, not the previous single-stage right-pivot criterion.

Fix q≤p, N'=q−1, and a COMMON agreement grade h with 2(h+1)>N'. Choose a set J of stages; each j∈J has a prescribed STRICTLY EARLIER physical anchor k(j)∉J matching the entire ordinary E_h signature. Anchors may differ by j. Let L=q−h−2 (if negative take the zero row space), and r_L be the rank of the full genuine one-mark matrix V_L restricted to the columns J. There is a physically strict order-q tableau on
    s−|J|+r_L
stages, with exactly |J|−r_L selected rows removed. In particular, writing S(q) for any valid lower bound on stage count over the same coefficient class,
    |J|−rank(V_(q−h−2)|J) ≤ s−S(q).
Take J as all nonfirst members of disjoint E_h-equal groups when suitable; they do not need pure class indicators. In the low f₁₀=11 four-mask application, the genuine indicators provide extra sharp rank information and guarantee rank on the nonfirst columns equals rank on the union at all the grades in question. The resulting cross-order necessary receipts are rk(V₆|J)≥|J|−1 at p19/s30, using S(18)=29, and rk(V₇|J)≥|J|−2 at p20/s32, using S(19)=30. These last two numerical lower bounds use the existing REAL min-stage results; the algebraic reduction itself has no positivity requirement.

Proof: retain a right-pivot basis of the columns of V_L on J, scanning them in reverse chronological order. For each nonpivot j choose a true w_j annihilated by V_L with its j-coordinate one, other entries confined to the STRICTLY LATER retained pivot sites in J. Thus no w_j changes an anchor or any other removed row, even when different choices of w have overlapping retained support. Set δ_j=a_j−a_k(j) (incoming rows of the original tableau), and replace A by
    A' = A−Σ_(nonpivot j) w_j δ_j .
This is strict: support of δ_j is entirely earlier than j, support of w_j is no earlier than j. Every selected nonpivot now has a literal input row identical to its own unchanged anchor. Check all target trees using the ORIGINAL A and b. Every nonzero innermost corrected primitive costs ≥h+1, since all original δ_j kill E_(h−1). Multiple incomparable outermost corrections would contain such an expensive primitive in each subtree and violate the target grade. If there is one outermost correction, its output is a multiple of its particular w_j, independently of what happened farther below. Its original same-parent and higher exterior has cost ≤N'−h−1=L, so it annihilates w_j. All changed coefficients vanish. Finally redirect each literal duplicate's column and output weight to its earlier retained anchor, then drop the row and column. No marked row belonging to a changed tableau is used in the proof. This is a sufficient rank guarantee, not a claim that every deletion has to be of this form. It is important here that h is common: with heterogeneous agreement grades an outer correction surrounding a lower-grade inner one need not itself first cost its nominal high grade.

A strictly stronger chronology-dependent version allows a set Q of extra retained sites, disjoint from both J and all anchors, available as additional correcting recipients. Scan J backwards. Delete a site whenever its evaluation column on V_L is in the span of all strictly later sites of Q and all already-retained later pivots in J. Keep it otherwise. Choose w_j using just those later retained correcting positions as above. The same proof gives every deletion in the scan, and hence a corresponding physical necessary resource count with the actual retained recipients. This is not a retroactive assumption that all later input signatures or rows are equal.
