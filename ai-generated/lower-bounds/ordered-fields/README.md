# Ordered fields

The real lower table transfers to every ordered field by its real closure. That is a statement about the theorem's scope, not a claim that each proof runs verbatim over an arbitrary ordered field. Direct ordered-field arguments use such tools as signed ordering or positivity of actual coefficients. Fixed rational Gram matrices, by contrast, may be proved nonsingular over the rationals and then used in characteristic zero. Proofs not yet classified as direct ordered-field arguments are not silently promoted here.
