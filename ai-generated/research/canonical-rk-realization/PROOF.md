# A canonical minimal RK realization from all rooted outputs

**Scope.** A finite tableau $(A,b)$ over a field $K$, with actual stages $K^s$ (coordinatewise multiplication), clock $c=A\mathbf1$, and raw rooted scalar series $f(t)=b^T\Phi_A(t)$. The structural theorem needs no ordering, sign or characteristic assumptions. Its order/payment consequences below use characteristic zero. Assume $f$ is not the zero series (in particular any positive-order method qualifies). Minimality always means fewest stages for the **same full scalar series**, in the stated class, not fewest stages among all possibly different series of a given classical order.

**Theorem.** Merge exactly those stages that have identical stage values on every rooted tree. Aggregate the matrix by these classes and sum weights within a class. In the aggregate graph $j\to i$ when the actual aggregate coefficient $\bar A_{ij}\ne0$, retain a class precisely when it can feed a nonzero aggregate output weight by a directed path, allowing length zero. The resulting principal tableau realizes the same full scalar series; it has minimum stage count, and every minimum-stage realization is the same up to stage permutation. ERK, lower triangular DIRK, invertible stage diagonals, and a prescribed common diagonal are preserved when classes are ordered by their earliest occurrence. Neither equality of the original $b,c$ nor any sign hypothesis is needed for uniqueness on minimal realizations.

## 1. Reachability is an algebra, not the tall Krylov span

For a rooted tree $t$ with children $u$, $\Phi_A(t)=\prod_u A\Phi_A(u)$ and the leaf gives $\mathbf1$. Merging the roots of $t$ and $u$ gives stage column $\Phi_A(t)\Phi_A(u)$. Putting a unary root above $t$ gives $A\Phi_A(t)$. Therefore

$$R=\operatorname{span}_K\{\Phi_A(t): t\text{ rooted}}\subseteq K^s$$

is a unital coordinatewise subalgebra closed under $A$, and the smallest such subalgebra. In contrast the span of $1,A1,A^21,\ldots$ alone need not be multiplicatively closed.

Partition the stage indices by agreement on every evaluation in $R$, equivalently on every individual tree. Each member of $R$ is constant on those classes. Conversely, for a class $i$ and each other class $j$, choose a tree column $u_{ij}$ with $u_{ij}(i)\ne u_{ij}(j)$. The product over $j\ne i$ of $(u_{ij}-u_{ij}(j)\mathbf1)/(u_{ij}(i)-u_{ij}(j))$ is the exact class indicator $e_i$ and is in $R$. Thus $R\simeq K^m$ for the $m$ distinct tree profiles. This indicator argument works even over a finite field; a single separating linear combination is not required. Distinct clocks already imply distinct stage profiles, but identical clocks need not imply equivalent stages.

For a row $a$ in stage class $i$, $A e_j$ has value $\sum_{k\in j}A_{ak}$ there; since $A e_j\in R$ this sum is independent of $a\in i$. Define $\bar A_{ij}$ by that sum, and $\beta_i=\sum_{a\in i}b_a$. Restriction to $R$ now literally is the aggregate tableau $(\bar A,\beta)$, including its clock and all tree scalars. Equivalently one can compute the class partition without generating trees: start with one color, and refine each class by the vector of row sums into current classes. Each strict round increases the number of classes. The algebra after a round is generated by its previous algebra and its image under $A$, so its entries are precisely the evaluations built at the corresponding bounded tree heights. At stabilization the partition is exactly the one for $R$. This gives a simple exact finite algorithm.

## 2. The only further redundancy is lack of a path to an aggregate output

On $R$ allow linear one-hole contexts obtained by composing $A$ and multipliers $M_u:v\mapsto uv$ with $u\in R$, and read them by $\ell(v)=b^Tv$. Using formal tree multipliers instead gives the same span, by linearity. Let

$$I=\{v\in R:\ell(Cv)=0\quad\text{for every such context }C\}.$$

The empty context is allowed. Right-composing $C$ with one more $A$ or $M_u$ shows that $I$ is an $A$-invariant ideal of $R$ contained in $\ker\ell$. It is the largest ideal with these properties. Every ideal in $K^m$ is supported on a subset of the coordinate idempotents.

Precisely the invisible class idempotents $e_j\in I$ are those from which **no** directed path reaches a class $i$ with $\beta_i\ne0$. For one direction the span of those idempotents is invariant under $\bar A$ and all multipliers, with zero readout. Conversely, for a path $j=i_0\to i_1\to\cdots\to i_a$ with $\beta_{i_a}\ne0$, use

$$M_{e_{i_a}}\bar A M_{e_{i_{a-1}}}\bar A\cdots\bar A M_{e_{i_0}}.$$

Its read is exactly $\beta_{i_a}\prod_{k=1}^a\bar A_{i_k,i_{k-1}}$ times the single input coordinate $v_j$, and the factor is nonzero. Thus there is no obstruction from signed cancellations among alternative paths: the gates select one actual aggregate path. The gates exist because **reachability was taken first**. Testing the original graph before merging can be wrong: a pair of nonzero incoming entries can cancel when their stages agree on all trees. Conversely zero weight at a visible stage is allowed if it feeds a weighted stage. The checker illustrates both situations.

The quotient $R/I$ is the split algebra $K^r$ on the visible classes. No visible row has a nonzero entry in an invisible column, so the induced $A$ is the principal submatrix on visible classes, not a Schur complement. It preserves the output and the clock restricted to those classes. Every remaining coordinate is observable in the quotient; projection of $R$ onto the quotient is surjective, so it is also reachable.

If the initial $A$ is lower triangular, order the merged classes by their earliest physical representatives. In the earliest row of a class, a later class contains only later stages, so its aggregate entry is zero. The aggregate diagonal at this row is just the original physical diagonal there, since other members of the same class are later. The class order after removal of invisible indices still has these properties. In particular reductions preserve strict explicitness, nonzero stage diagonals, or a common prescribed diagonal. Extra requirements such as retaining a mandated physical index, a chronologically chosen end formula, or specific fixed-length $b,c$ are not covered by this preservation claim.

## 3. Canonical construction and uniqueness from the scalar series

Let $\mathcal T$ be the formal $K$-span of finite rooted trees, product given by root merger, unit the leaf, and linear operator $a$ given by adjoining a unary root. It is generated from its unit by these operations. A formal context is a word in $a$ and multiplication by formal trees. Extend $f$ linearly, and form the all-order one-hole matrix $H(C,t)=f(Ct)$. Its column radical is

$$J_f=\{x\in\mathcal T:f(Cx)=0\text{ for all formal contexts }C\}.$$

It is an ideal stable under $a$. Evaluation $E:\mathcal T\to R$ is a surjective unital algebra map intertwining $a$ and $A$. By its definition and the available multipliers, $J_f=E^{-1}(I)$. Thus

$$\mathcal T/J_f\simeq R/I,\qquad r=\dim_K(\mathcal T/J_f)=\operatorname{rank}H.$$

The rank means the rank of the map to all context coordinates, equivalently the supremum of finite nonsingular minors. This quotient, its unit, induced unary operator, and output are intrinsic to $f$. Every realization with $s$ stages factors $H$ through $K^s$ and hence has $s\ge r$. The representative just constructed has $r$ stages. In a class stable under the chronological reduction above, the same minimum holds within that class. A tableau of actual minimum size for its exact classical order within such a class is in particular minimal for its own full series, since these reductions preserve every order. The converse is not true.

Any two minimum-stage realizations give isomorphisms of the same intrinsic algebra $K^r$. A unital $K$-algebra isomorphism permutes its primitive idempotents, i.e. is a stage permutation $\Pi$. It intertwines $A$ and preserves the output, so $A'=\Pi A\Pi^{-1}$, $b'=\Pi b$, $c'=\Pi c$. If two physical lists $b,c$ are already aligned and equal, only permutations preserving both lists are possible. In particular if the clocks are pairwise distinct and the clock lists are equal, the two matrices themselves are equal. There is no claim that the scalar series intrinsically labels independent physical stages or chooses one compatible chronology. Without minimality, equal $b,c$ and the full series do not force permutation; the earlier quartic example reduces both tableaux to the same smaller object.

This proof gives a data-only reconstruction with full rooted data. Select a nonsingular $r\times r$ block with contexts $C_i$ and basis trees $t_j$. The coordinates of the class of $x$ in that basis are given by the linear solve with right side $(f(C_i x))_i$. Apply it to the leaf, to each $a t_j$, and to each $t_jt_k$. This recovers the unit, unary operator, and multiplication table, while $f(t_j)$ recovers the output. Read $A$ and $b$ in the primitive idempotent basis of this split algebra. The same solve directly expresses an arbitrary rooted expression in basis coordinates. In the particularly simple case of $r$ distinct clocks and all weights nonzero, the Lagrange idempotents $e_i(c)$ are already explicit and

$$b_i=\ell(e_i(c)),\qquad b_i A_{ij}=\ell\big(e_i(c)\,A e_j(c)\big).$$

Those scalar tree combinations use orders at most $2r$ when the clocks are given. Zero weights require the path contexts or equivalent observable rows instead.

## 4. Exact decomposition of true Early packet loss

Take a polynomial mask $P$ and $T=DA-AD-A^2$, with $D$ multiplication by the actual tableau clock. Every masked seed $P(c)c^e$ lies in $R$, and both $R$ and $I$ are stable under $T$. Thus the canonical projection $\pi:R\to R/I$ sends each actual column $T^a(P(c)c^e)$ to the identically constructed canonical column. For an Early physical cut covered by $P$, these global columns are the zero extensions of the counted suffix columns since triangularity preserves suffix support. Their rank and loss are independent of any compatible relabeling that leaves the same $P$ and its legally covered cut; arbitrary chosen chronology is not itself part of the scalar series.

For any such packet span $F\subset R$, write $\bar F=\pi F$ and $z(F)=\dim(F\cap\ker T)$. Rank-nullity gives the exact identity

$$z(F)=z(\bar F)+\dim(F\cap I)-\dim(TF\cap I).$$

More precisely there is an exact sequence

$$0\longrightarrow F\cap I\cap\ker T\longrightarrow F\cap\ker T\longrightarrow
\bar F\cap\ker\bar T\xrightarrow{\partial}(TF\cap I)/T(F\cap I)\longrightarrow0,$$

where $\partial(\pi v)$ is the class of $Tv$. The definitions give well-definedness; the obstruction to replacing a lift by a true kernel vector is precisely its class in the final quotient. This identifies the information missing from rooted outputs: merging identical tree-stage coordinates does not change the rank of any tree-generated column span, but invisible exports may convert a genuine canonical kernel vector into one with a nonzero unseen image, and invisible seeds may add hidden kernel directions. For a minimal realization $I=0$ and the full rooted data fix every such actual packet loss. This is a primal Early statement; no analogous formula for arbitrary extra coordinate vectors or raw dual packets is assumed here.

An exact replay of the previous, all-orders-identical quartic pair gives, at order 20, 865 original stages, 443 distinct profiles, and the **same** chronological 423-stage minimal tableau for both variants. At order 8 it gives 157, 83, and the same 75-stage minimal tableau. Those examples altered the invisible lift, not the intrinsic RK output. The new finite-horizon examples in the separate note are already minimal and therefore cannot, and do not, match forever.

## 5. Finite bounds and what remains promising for a stage floor

A conservative finite **equivalence** cutoff is available when a stage bound is known. For a $d$-stage tableau (or direct sum) start with $W_0=K\mathbf1$ and iterate $W_{k+1}=W_k+AW_k+\operatorname{span}(W_k W_k)$. The first equality implies full reachable closure. Since each strict step grows the dimension, at most $d-1$ are needed. Define stage grade as tree order minus one. If $W_k$ is spanned by expressions of grade $g_k$, one can use $g_{k+1}=\max(g_k+1,2g_k)$, starting at zero. Thus $R$ is spanned through grade $g(d)=2^{d-2}$ if $d\ge2$, and grade 0 if $d=1$. Apply this to the disjoint union of two matrices with opposite output signs on the second block: equality of scalars through order $g(s+s')+1$ forces equality at every order. This bound is deliberately large, not a tight horizon.

Similarly, on the minimal $r$-stage realization, grow the span of output rows by right-composition with $A$ and all multipliers from $R$. It either becomes stable or grows by at least one at each iteration, and must eventually have rank $r$. Using grade $g(r)$ representatives of each reachable multiplier, an $r$-minor has rows of cost at most $(r-1)\max(1,g(r))$ and basis tree columns of grade at most $g(r)$. The reconstruction just given needs only the same contexts with the leaves, products and unary images, once a full-size minor is identified. These statements give finite witnesses for recognized complete data or bounded-comparison problems, not a shortcut to a paid high-order rank from a low-order certificate.

For **paid data only**, the earlier one-hole formula gives a sharp elementary limit. In any one-hole matrix rectangle whose every entry is paid, let $n$ be the maximum input tree order and $C$ the maximum context cost. Then $n+C\le p$. In the formal integral model, a normalized input of order $j$ is $x^{j-1}$. Along its path, each $A$ divides the coefficient by $j+h$ at the accumulated cost shift $h$, and the final integral contributes $1/(j+C)$. The shifts are distinct, so partial fractions in $j$ express this row as a linear combination of ordinary probes of degrees at most $C$. Each normalization affects only the input forest factor. Thus columns depend only on their input order (one per order $1,\ldots,n$). Hence

$$\operatorname{rank}H_{\rm paid}\le \min(n,C+1)\le \lfloor(p+1)/2\rfloor.$$

The ordinary square moment/Hilbert block of size $\lfloor(p+1)/2\rfloor$ attains this over characteristic zero, so more decorations cannot improve the universal rank of these fully paid rectangles. This is **not** a no-go for rooted algebraic lower bounds using extra structural equations, nonrectangular information or real signs. For example an ERK with at most $p$ stages has $A^p=0$, making the tall-only block $H_{ij}=b^T A^{i+j}\mathbf1$, $0\le i,j<p$, zero for $i+j\ge p$ even though these entries are unpaid. Its paid anti-diagonal $i+j=p-1$ is $1/p!$ by order $p$, so the rank is $p$; this proves the usual ERK stage floor $s\ge p$. It uses actual triangular structure, not decoration alone.

A viable rooted-data route is therefore to exploit algebra and structural completions: unknown unpaid entries must extend to an $A$-invariant split unital algebra with an observable output, and in a triangular class its reconstructed unary matrix must have a compatible triangular order, diagonal and structural zeros. Commutativity, multiplication identities, or a sign-specific sum of squares can add constraints not present in a rectangular paid rank. Equivalently the minimum over allowable series extensions equals the least rank of a finite-rank all-context extension whose quotient is split and whose unary operator has the required chronological form. The theorem does not give a new numerical order-20 floor. The new minimal exact-order pairs show that finite paid data plus reachability/observability, **even with fixed actual $b,c$ and distinct clocks**, do not determine early quartic packet loss with no stage budget. Size-constrained reasoning for a specific low-stage class remains open to these extra structural inputs.
