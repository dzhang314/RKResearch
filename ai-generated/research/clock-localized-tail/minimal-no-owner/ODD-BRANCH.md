# Odd reverse grade: a viable canonical chart needs a cyclic three-dimensional defect

Use the notation of [Active tail and canonical abscissae](ACTIVE-TAIL.md) and the marked-source rank in [Marked source interpolation](MARKED-SOURCE.md). This is a necessary branch description, not another nonexistence claim. Assume \(r\ge5\) is odd, the canonical reflected distinct abscissae, \(\gamma<0\), and a hypothetical full exact no-owner method at \(d=L(r)\).

1. The actual numerical word spaces satisfy \(N_2=\operatorname{span}\{b\Omega\}\), \(N_4=V_2\Omega\) of dimension four, by parity saturation. The literal first row identity \(bT=b(M-\gamma I)\) and nonzero first two active weights follow from §3 of ACTIVE-TAIL.md, without assuming even parity. Thus \(V_1=\operatorname{span}\{b,bM\}\), and \(V_1\Omega\subseteq N_3\), so \(\dim N_3\ge2\).
2. There is no nonzero \(M\)-invariant subspace of \(N_4\). Every element of \(N_4\) kills the actual late column of the shifted order-\(m\) tall head, whose values are \(W_{m-1}(x_i)/(m-1)!\) and are all nonzero on the exterior grid. This is a true rooted order test through \(m+4\). On a distinct diagonal, a nonzero invariant space contains a coordinate axis by spectral cardinal projectors, giving a contradiction.
3. If \(\dim N_3=4\), then \(N_3=N_4\), and mark closure \(N_3 M\subseteq N_4\) would violate step 2. If \(\dim N_3=2\), it equals \(V_1\Omega\) and the whole grade-three proof of §4 applies: it uses exactly that kernel and the first row identity, not parity otherwise. The canonical singleton contradiction follows. Hence a hypothetical odd solution has precisely \(\dim N_3=3\).
4. Since \(N_3+N_3 M\subseteq N_4\) and \(N_3\) is not invariant, the dimension increases by exactly one. It follows that
\[
      N_3=\operatorname{span}\{h,hM,hM^2\},
          \qquad N_4=\operatorname{span}\{h,hM,hM^2,hM^3\}
\]
for a nonzero actual row \(h\). For completeness set \(Q_j=\{v\in N_3:vM^a\in N_3\text{ for }0\le a\le j\}\). The quotient map \(Q_j/Q_{j+1}\to Q_{j-1}/Q_j\) given by \(M\) is injective, so the codimension at each step is at most its first value one. A flat nonzero step would give an invariant subspace, so \(Q_2\) is one-dimensional. Any nonzero \(h\) in it has three independent successive marks, since a first dependence would again yield a nonzero invariant subspace. This proves the displayed flag.
5. For balanced orders with \(r\ge7\), the full actual \((X-\alpha)\mathbb P_{\le p-6}\) source band is visible to \(N_4\) by the modular saturation threshold: the available \(r-4\) marks are enough. Since \(hM^0,\ldots,hM^3\) all belong to \(N_4\), the seed \(h\) annihilates \((X-\alpha)\mathbb P_{\le p-3}\). Distinct-site Vandermonde rank therefore forces at least \(p-1\) nonzero coordinates of this one cyclic seed. In particular this is a necessary actual low-shelf shape at the unresolved compatible canonical orders \(14,15,18,19\), not an extension of the even-order exclusion. The quotient form also requires the four rows \(b\Omega,bM\Omega,bM^2\Omega,bT^2\Omega\) to be a basis of one weighted cubic-evaluation space, with the first two in its weighted quadratic part. This is a more direct finite input for odd-shelf search than arbitrary same-count formal compression.
