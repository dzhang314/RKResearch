# Frozen exact specialization guard inputs

These ascending-coefficient rational polynomials are the primitive
squarefree supports of the named multiplication norms. They are
exactly the outputs of the adjacent checker, not hand-transcribed
inverses or residue factorizations. In particular the first gap leader
and the fourth-clean primitive data are retained separately.

From the parent notebook directory, with python-flint 0.9.0:

    mkdir -p /path/to/new/guards
    python3 rank.py --p 0 --trace-guards --write /path/to/new/guards
    for f in guard-inputs/G*.txt; do
        cmp "$f" "/path/to/new/guards/$(basename "$f")"
    done
    (cd guard-inputs && sha256sum -c sources.sha256)
    bash run-guard-ranks.sh guard-inputs

The exact paired first-norm build is the following independent step.
The raw first polynomial alone takes 314,209,132 bytes in the
deterministic text representation. The ledger takes about 150 KB.
Regenerate to a single empty staging directory; the guard-only checks
above do not write this large file. After the exact filters have run,
only the 8.5 MB cofactor, textual hashes and small ranks are needed.

    compact=../dirk11-thirteen-invisible-six-cubic-compact-projection
    mkdir -p /path/to/staging/first
    python3 "$compact/project.py" --p 0 --chart pair --first-only \
        --write /path/to/staging/first
    python3 divide-guards-first.py /path/to/staging/first/pair-quintic.txt \
        --guards guard-inputs --ledger /path/to/staging/first/ledger.txt \
        --out /path/to/staging/pair.txt
    python3 check-pair-support.py /path/to/staging/pair.txt \
        /path/to/staging/pair.guards /path/to/staging/first/ledger.txt
