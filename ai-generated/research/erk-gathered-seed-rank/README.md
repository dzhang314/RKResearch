# Fixed gathered Stepanov seed: exact rank ceiling

[Fixed-seed proof](FIXED-SEED.md) proves that five arbitrary strictly explicit stages appended to the stated fifteen-stage seed give at most seven independent exact scalar functionals through rooted order nine. The archived 20-stage continuation attains seven. It does not exclude changes inside the seed or improve an unrestricted stage bound.

[Two-stage bound for moment-based seeds](TWO-STAGE-GROWTH.md) generalizes the obstruction under its exact old-rank and fibre hypotheses. The optional Cauchy construction requires an admissible earlier coincident slot to choose the normalizer freely, or a separately nonzero normalizer. The original exact coefficient and replay files are retained as archived supporting evidence; the new symbolic proof did not run the historical replay again.
