## Actual fifth condition even when a selected pivot vanishes

For any three-dimensional choice \(I\) of the four coefficient rows, denote the three-column leading square block by \(A_I\) and the last column by \(b_I\), using the unscaled nodal coefficient formulation. The actual ordinary nodal polynomial is \(E R\), \(R\) monic cubic, and on these rows the actual lower coefficient vector \(\boldsymbol r\) satisfies \(A_I\boldsymbol r=-b_I\). Write
\[
 R_I(X)=\det(A_I)X^3+\sum_{j=0}^2 \operatorname{cramer}(A_I,-b_I)_j X^j .
\]
Cramer's identity says \(R_I=\det(A_I)R\) at any true solution, including when the selected determinant is zero. Thus \(R_I\) is identically zero when the selected pivot vanishes at a true solution. This removes any need to assert an unknown actual pivot is a unit.

Physical fifth is ordinary, and is different from all five pegs. Its true normalized clock \(Y=c_5/\gamma\) is a root of each \(R_I(\gamma Y)\). This gives an exact polynomial \(E_5(Y)\) of degree at most six. No reverse rank-two assumption on the literal fourth or fifth is made.
