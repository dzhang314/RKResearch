# Proving order from a filtration of stage residuals

The [general filtration theorem](../../lean/RKCert/ReviewedNative/DefectFiltrationOrder.lean) proves the reviewed order conditions directly from the tree recursion. Write (B=zA) and (x=B\mathbf 1). For a tree (t), multiply its Butcher weight vector by the product of the factorials of its root branches, then subtract the coordinatewise power (x^{|t|-1}). The theorem places this difference in a prescribed submodule at index (|t|-1). The required submodule relations are precisely those for adjoining a branch: multiplication by the clock, application of (B), and products of lower-order residuals. If the output row vanishes on these submodules, only the quadrature moments remain. The argument takes place over a commutative ring and cancels only powers of a regular normalization scale.

[The order-six certificate](../../lean/RKCert/ReviewedNative/DefectTestsSix.lean) instantiates these submodules with the quadratic residual, two explicitly spanned cubic directions, and the kernels of one or two weighted moments. It needs no restriction on the diagonal or the number of stages. A companion [transport theorem](../../lean/RKCert/ReviewedNative/DefectTestsSixTransport.lean) shows that a linear equivalence preserving the matrix action, clock multiplication, all-ones vector and output row preserves all the linear tests. The two square moments must still be checked separately; the equivalence need not preserve coordinatewise products.

[An exact strict SDIRK example over `ZMod 163`](../../lean/RKCert/ReviewedNative/SDIRKSix163AllWeights.lean) has six stages and all six output weights nonzero: (33,19,160,85,72,121). Lean proves order six with the residual test, not a tree enumeration. The seventh bush condition has cleared value 12 instead of 1. Thus this second witness shows that the finite-characteristic exception does not depend on vanishing output weights. It changes no characteristic-zero bound.
