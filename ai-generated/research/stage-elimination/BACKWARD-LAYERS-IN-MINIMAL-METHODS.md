# Forward independence on backward layers

Let \(E_h\), \(H=p-1\), \(\varepsilon_i\), and the actual shortest dependency distances \(D_i\) have the definitions in the named row note. Work over a field. For each stage set
\[
 \rho_i\coloneqq \min\{h\ge0:\varepsilon_i|_{E_h}\notin
    \operatorname{span}(\varepsilon_j|_{E_h}:j<i)\},
\]
with value \(\infty\) if the set is empty. In a stage-minimal order-\(p\) tableau, \(E_H=K^s\): if not, an annihilating relation lets one eliminate its rightmost pivot by replacing that stage derivative with a linear combination of earlier ones through order \(p\). The extension recurrence uses that relation on children and the output uses it on the root. Thus \(\rho_i\le H\) in a minimal tableau. Every stage also has a path to output, since otherwise it can be deleted without changing the output.

The stronger local condition is
\[
 \boxed{\rho_i+D_i\le H\qquad\text{for every physical stage }i.} \tag{4}
\]
In fact there is a chronological relation recovering the \(i\)-th evaluation from earlier stages through degree \(\rho_i-1\). For \(\rho_i=0\), this is the vacuous relation below degree zero, and the restoration may be chosen as zero. Deleting and restoring \(i\) in this way first changes a read at the extension above a child of degree at least \(\rho_i\). Any effect on an output must travel at least \(D_i\) strict edges in all, including its initial edge, or is the direct output correction if \(D_i=0\). A multiplication at a root keeps the same physical row and cannot shorten a path. The changed strict coefficients are in earlier columns than \(i\), and cannot shorten a path for an error arising at \(i\) or farther downstream. Thus the first possible output discrepancy has degree at least \(\rho_i+D_i\). If this exceeded \(H\), the deletion would preserve the required order and the diagonal class.

In particular, for any named set \(G\) lying at backward distance at least \(H-h\), where \(0\le h\le H\), we have
\[
 E_h|_G=K^G. \tag{5}
\]
If the restricted evaluation were not onto, choose a nonzero relation among its rows and inspect its rightmost pivot. That stage would be dependent on earlier stages through degree \(h\), contradicting (4). Equivalently, in chronological order each of the selected evaluations is independent even of *all* preceding original evaluations on \(E_h\); consequently the rank increments at every selected coordinate. This works within any actual prefix: all tree evaluations on that prefix are exactly those of its own lower-triangular principal submatrix. In particular the number of selected stages cannot exceed the corresponding rank in that prefix, not merely a root-count upper bound on the global tableau.

## Restricting to one observed clock, or to a finer group

On a named set \(G\) of equal clocks, each root leaf contributes the same scalar factor to \(\boldsymbol\Phi_t|_G\). Removing all those root leaves therefore shows that \(E_h|_G\) is spanned by rooted trees of total order at most \(h+1\) having no leaf attached directly to the root. The number of these reduced shapes is exactly the number \(T_{h+1}\) of all rooted tree shapes of order \(h+1\): pad the removed number of vertices by leaves directly attached to the root, with inverse given by stripping those leaves. This counts a spanning set, not necessarily independent vectors. If the common clock is nonzero, padding individually also shows that the restricted full flag equals the span at the last tree order alone. If the clock is zero, a tree with a root leaf simply contributes zero.

Thus a stage-minimal tableau can have at most \(T_{h+1}\) actual stages of one clock at distance at least \(H-h\). For \(h=0,1,2,3\) the counts are respectively \(1,1,2,4\). In particular, at \(h=2\) two such stages must have different \(A\mathbf c\) entries, because on that clock the other tree vectors through degree two are constant. At \(h=3\) the restricted span is generated by the constant vector and the actual restrictions of \(A\mathbf c\), \(A(\mathbf c^{\odot2})\), and \(A^2\mathbf c\), where \(\mathbf c\coloneqq A\mathbf1\).

More generally, if a root factor \(\boldsymbol\Phi_{[u]}\) is already measured constant on \(G\), it too may be stripped when forming a spanning set for \(E_h|_G\). For example, if all signatures through degree \(k\) are common on \(G\), only root children of size at least \(k+1\) need be retained. When \(h<2(k+1)\), at most one such child survives, giving
\[
 \dim(E_h|_G)\le 1+\sum_{j=k+1}^h T_j.
\]
If the whole forward signature through degree \(h\) is common on a named group, (5) shows that at most one member can be at backward distance at least \(H-h\). These deductions use equality on the actual stages, not merely membership in a fibre predicted by a quotient character.

## Using genuine backwards visibility instead of paths

Let \(\mathcal C_r\) be the ordinary output-context space, as defined in the companion note, and let \(\beta_i\) be the first cost at which some actual ordinary output context has nonzero \(i\)-th coordinate. It may be infinite. For every integer \(d\le H\) with \(d\le\beta_i\), choose \(h=H-d\). If \(H<2(h+2)\), a dependency of the \(i\)-th evaluation through degree \(h\) would permit deletion: all contexts through cost \(d-1\) miss that pivot and no output through degree \(H\) can contain two independently changed branches. This is the direct two-sided cut proof in the previous seal, also recovered by the selector-gap note when its gap is irrelevant. Therefore stage minimality gives \(\rho_i\le H-d\) under this paid window. In particular this improves on (4) when several shortest actual paths cancel in all requisite ordinary contexts. A separate filtered selector calculation in the companion note removes the short-window hypothesis when the physical response admits a sufficiently low-degree lift. No condition here is inferred from graph lengths when ordinary context cancellation is used.
