# Erratum: the effective three-row support in the delayed quadratic example

This corrects only the final support illustration in `LITERAL-DELAY-SHARPNESS.md` of the original source package, manifest `8600fe14d5a4c2af5626661f2ca538583569793f8425edde972503cf98684b47`. The two stage-elimination theorems and their inequalities are unchanged.

In the three-row blocks of that example, use labels \(\theta=1,2,3\), rather than \(0,1,2\), with the same order and ultimate weights \((1,-2,1)\). Each row of a later block still reads its equally labelled predecessor with coefficient one. The signed feeds into \(i,i'\) remain \((\theta,-\theta)\); the original stage histories therefore remain constant on each block. The moment identities are \(1-2+1=0\), \(1-4+3=0\), and \(1-8+9=2\), so the ordinary-visibility and delayed-square calculations are identical. In the final exact Gram the value is now directly \(1-8+9=2\). Crucially all three strict first-responder coordinates are nonzero. Their effective named set \(\operatorname{supp}(\mathbf w\odot\mathbf u)\) therefore really does have three rows with zero aggregate transported weight. The previous zero label would have been outside that effective support, leaving two responding rows and transported aggregate \(-1\), so it did not illustrate the three-effective-row statement.

In the strict SDIRK version take \(\gamma\) to be the common diagonal of the supplied base, on every new row. The counterpart choices in ERK and unrestricted DIRK are unchanged. These clarifications retain all original chronology, tree expansions and scope limits. No immutable source was modified.
